# 🏥 Consultorio con JS (y ES5)

📋 Descripción del Proyecto
Este proyecto es una solución en JavaScript para un consultorio médico. El programa está diseñado para gestionar los datos de los pacientes, permitiendo almacenar, modificar y buscar información de forma organizada.

La actividad se desarrolló utilizando el paradigma de la Programación Orientada a Objetos (POO) bajo la sintaxis ES5 de JavaScript, empleando funciones constructoras y la propiedad prototype. 

##  Características
- Código en JavaScript ES5 (sin `class`, `let`, `const`)
- Funciones constructoras para `Paciente` y `Consultorio`
- Métodos con `prototype` para búsqueda y visualización
- Encapsulamiento con getters y setters
- Interfaz visual con HTML y CSS
- Búsqueda interactiva en pantalla + salida en consola

##  Cómo usar
1. Abre `index.html` en tu navegador.
2. Revisa la consola para ver todos los pacientes.
3. Usa el buscador para filtrar por nombre
4. Una vez que la página esté cargada, abre las herramientas de desarrollador presionando F12.
5. Ve a la pestaña "Console". Aquí podrás ver la salida de los métodos, incluyendo el listado de pacientes, los resultados de la búsqueda y la actualización de un dato a través de un setter.
